# Security Policy

For the MCP package's supported versions, boundaries, and private reporting process,
see [`packages/mcp/SECURITY.md`](packages/mcp/SECURITY.md).

Report repository vulnerabilities privately through
[GitHub Security Advisories](https://github.com/im-shadowpool/compressbyurl/security/advisories/new).
Do not include real secrets, private files, or third-party data in a report.
