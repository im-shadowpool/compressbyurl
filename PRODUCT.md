## Product Purpose

Compress, resize, and convert static images in the browser, starting from local files, a public image URL, or image candidates discovered on one public webpage.

## Capabilities and Constraints

Local file bytes remain in the browser. Workers perform bounded compression. URL services fetch only validated public resources. Static JPEG, PNG, WebP, and AVIF are supported; animated optimization, accounts, and full-site crawling are excluded. Editorial pages must describe these boundaries accurately.
