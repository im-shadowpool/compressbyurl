# 18 — SEO Page Specifications

## Shared indexable tool-page anatomy

1. Breadcrumb when useful
2. Unique H1
3. Short intent-matched value paragraph
4. Working tool with route preset
5. Privacy/trust note
6. How it works
7. Supported formats/limits
8. Examples or use cases
9. Helpful FAQ
10. Related tools
11. Related guide

## Example: Compress PNG

Route: `/compress-png`

Preset:
- accepts PNG
- Keep Original output by default
- PNG optimization path active

Suggested title: `Compress PNG Images Online | CompressByURL`

Suggested H1: `Compress PNG Images Online`

## Cannibalization rule

Do not create separate pages only because keyword wording differs slightly. `compress by url`, `image url compressor`, and `compress image from url` may be better served by one canonical primary page plus supporting wording. Use Search Console data before splitting intent.

## Competitor page anatomy

- transparent alternative intent
- factual comparison table
- when competitor may fit better
- when CompressByURL fits better
- URL/scanner differentiator
- capability verification date internally
- no defamatory or absolute superiority claims
