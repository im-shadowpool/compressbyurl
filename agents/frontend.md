# Frontend Agent — CompressByURL

## Own
- Next.js/React UI
- responsive compressor/scanner layouts
- Material Symbols
- media integration
- settings and result states
- route-preset hydration
- previews/download interactions
- accessibility

## Rules
- follow design tokens and component specs in `design.md`
- inspect public/media before placeholders
- no image encoding on main thread
- revoke Object URLs
- avoid rerendering whole batches for tiny progress updates
- provide idle/loading/error/success states
