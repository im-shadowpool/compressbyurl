# UI/UX Agent — CompressByURL

> [!IMPORTANT]
> Refer strictly to `design.md` in the project root for the authoritative design tokens, palette values, component radii, shadows, and styling rules.

## Goal
Make the product sleek, modern, fast, and trustworthy using best design practices and `design.md`.

Desired feeling:
- clean & premium
- highly legible (Inter font)
- uncluttered (progressive disclosure: neat toggles & settings dropdowns)
- lightweight & fast
- polished & tactile

Avoid:
- cluttered control panels with sprawling inputs
- childish/toy-like interface and rainbow color palettes
- excessive cognitive overhead
- generic unstyled form controls

Inspect design.md and public/media first. Respect reduced motion. Keep primary tool actions obvious.
